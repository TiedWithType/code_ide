Syntax Highlighting

Code IDE selects a language using the file name or extension. Some modes also recognize a script's first line. Highlighting does not compile or type-check your code.

  • Choose a language

  • Disable highlighting

HTML, CSS and JavaScript

HTML delegates script blocks and event attributes to JavaScript, and style blocks and inline styles to CSS. HTML entities, custom element names and Shadow DOM attributes have dedicated rules.

JavaScript, TypeScript, JSX and TSX share ECMAScript keywords and browser/Node.js globals, including console, document, fetch and customElements. Common console method names, including log, warn and error, are highlighted as functions; these names also receive that color on other objects. TypeScript adds type keywords and utility types such as Partial and ReturnType.

const greeting = `Hello ${user.name}`;
console.log(greeting);
const response = await fetch('/api/items');

Use JSX for .jsx and TSX for .tsx. TypeScript handles .ts, .mts, .cts and their declaration files. JSONC supports comments in tsconfig.json and jsconfig.json. CSS mode is intended for CSS; SCSS and Less require their own grammar.

Choose a language

  1. Open File Actions → Force Syntax….
  2. Select the language.
  3. Choose whether to remember the association for this extension.

Saved custom associations can override automatic detection. If a file opens with the wrong language, use Force Syntax to update the association. Shared extensions such as .h cannot uniquely identify a language; select C or C++ as needed. SQL dialects and older ambiguous formats can also be selected manually.

Grammar files

This build uses XML mode definitions in assets/syntax/modes, a catalog of file associations and imported rule sets. Shared ECMAScript rules, JavaScript keywords, TypeScript types, platform APIs and markup entities are kept in separate common-*.xml files.
