Emmet 2.4.11

Oficjalny silnik Emmet rozwija skróty HTML, XML, CSS i JSX. Działa offline dzięki wbudowanemu pakietowi JavaScript i systemowemu Android WebView.

Jak używać

Wybierz właściwą składnię dokumentu. Wpisz skrót i ustaw kursor na jego końcu albo zaznacz sam skrót. Wybierz Edytuj → Rozwiń Emmet lub naciśnij Ctrl + Space na klawiaturze sprzętowej.

Rozwinięcie zachowuje wcięcie bieżącego wiersza, ustawiony znak tabulacji i zakończenia linii. Kursor trafia do pierwszego pola do uzupełnienia. Nie ma przechodzenia klawiszem Tab po kolejnych polach ani automatycznej listy podpowiedzi.

Dostępne są zagnieżdżenia >, sąsiedzi +, wyjście poziom wyżej ^, grupy, mnożenie, numeracja, identyfikatory, klasy, atrybuty i tekst. Obsługiwane są też tryby XHTML, SCSS, Sass i Stylus, jeśli wybierzesz je jako składnię.

W HTML silnik rozpoznaje proste bloki <style>, atrybuty style i rodzica dla skrótów takich jak .item w liście. Nie rozwija skrótów w komentarzach, zwykłych atrybutach ani blokach skryptu. Rozpoznawanie kontekstu jest uproszczone; dla złożonych szablonów wybierz odpowiedni tryb dokumentu.

Ograniczenia

Emmet wymaga działającego Android WebView. Dokumenty powyżej 512 Ki znaków, skróty powyżej 4096 znaków i wyniki powyżej 256 Ki znaków są odrzucane. Duże powtórzenia są ograniczone. Jeśli podczas obliczania zmienisz tekst, zaznaczenie lub dokument, wynik nie zostanie wstawiony. Ta integracja udostępnia rozwijanie skrótów, bez pozostałych poleceń edytorowych Emmet i własnych snippetów użytkownika.
