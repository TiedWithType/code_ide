Emmet 2.4.11

Oficjalny silnik Emmet rozwija skróty HTML, XML, CSS i JSX. Działa offline dzięki wbudowanemu pakietowi JavaScript i systemowemu Android WebView.

Jak używać

Wybierz właściwą składnię dokumentu. Wpisz skrót i ustaw kursor na jego końcu albo zaznacz sam skrót. Wybierz Edytuj → Rozwiń Emmet lub naciśnij Ctrl + Space na klawiaturze sprzętowej.

Rozwinięcie zachowuje wcięcie bieżącego wiersza, ustawiony znak tabulacji i zakończenia linii. Kursor trafia do pierwszego pola do uzupełnienia. Tab przechodzi do kolejnego pola, Shift+Tab wraca do poprzedniego. Przycisk tab na dodatkowej klawiaturze aplikacji także przechodzi dalej. Edycja poza aktywnym polem lub zmiana dokumentu kończy sesję pól. Nie ma automatycznej listy podpowiedzi; powtórzenia tego samego pola nie są automatycznie synchronizowane.

Dostępne są zagnieżdżenia >, sąsiedzi +, wyjście poziom wyżej ^, grupy, mnożenie, numeracja, identyfikatory, klasy, atrybuty i tekst. Obsługiwane są też tryby XHTML, SCSS, Sass i Stylus, jeśli wybierzesz je jako składnię.

W HTML silnik rozpoznaje proste bloki <style>, atrybuty style i rodzica dla skrótów takich jak .item w liście. Nie rozwija skrótów w komentarzach, zwykłych atrybutach ani blokach skryptu. Rozpoznawanie kontekstu jest uproszczone; dla złożonych szablonów wybierz odpowiedni tryb dokumentu.

Własne snippety

Otwórz Snippety Emmet w menu edytora. Wprowadź JSON i naciśnij Zapisz. Klucze pierwszego poziomu to języki (html, jsx, xml, xhtml, css, scss, sass, stylus), a następnego: skróty. Wartością jest rozwinięcie Emmet. Przykład:

{"html":{"card":"article.card>h2{${1:Tytuł}}+p{${2:Treść}}"},"css":{"brand":"color: #6750a4;"}}

Pola zapisuj jako ${1:tekst}, ${2:tekst} itd.; ${0} oznacza pozycję końcową. Snippety zapisują się prywatnie w aplikacji i działają offline. Pusty obiekt {} przywraca sam zestaw wbudowany. Limit: 200 snippetów, 32 Ki znaków JSON, 4096 znaków rozwinięcia. Błędny JSON nie zastępuje poprzednich ustawień.

Ograniczenia

Emmet wymaga działającego Android WebView. Dokumenty powyżej 512 Ki znaków, skróty powyżej 4096 znaków i wyniki powyżej 256 Ki znaków są odrzucane. Duże powtórzenia są ograniczone. Jeśli podczas obliczania zmienisz tekst, zaznaczenie lub dokument, wynik nie zostanie wstawiony. Ta integracja udostępnia rozwijanie skrótów, bez pozostałych poleceń edytorowych Emmet.
